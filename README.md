# 画板（huaban）

一个纯 HTML 单文件的手机画板，整个应用只有一个 `index.html`，没有任何依赖，双击就能用。

## 功能

- **九种笔**：铅笔、圆笔（拖出一个圆）、钢笔（粗线）、签字笔（细线）、水彩笔（半透明）、马克笔（超粗）、颜料（整屏填充）、荧光笔（固定黄色高亮）、图形印刷器（拖出矩形）
- **取色**：原生取色器
- **笔宽**：1–50 可调
- **橡皮擦**：白色铅笔
- **撤销**：按下笔时存一帧，点一次退一步

## 怎么用

```
直接用浏览器打开 index.html
```

手机上推荐用支持 WebView 的浏览器或打包工具（本项目最初是用 WebCat 打包成 APK 的）。

## 目录

```
index.html   # 全部代码，HTML + CSS + JS 都在里面
```

## 已知限制

- 目前只监听 `touch` 事件，**桌面浏览器用鼠标画不了**，需要补 `mousedown/mousemove/mouseup` 映射
- 撤销用的是一帧一整张画布，画得多了内存会涨，后续可改成笔画路径栈
- 没有保存/导出图片功能
- 窗口尺寸变化会清空画布
